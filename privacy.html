Política de privacidad

Última actualización: 14 de septiembre de 2026.

Datos que tratamos

Usamos tu cuenta de Google para identificarte y el acceso que autorizas a Google Sheets y Drive para mostrar, crear, editar y formatear las hojas que eliges dentro de LittleAPI.

Cómo usamos Google

LittleAPI solicita permisos de Google únicamente para operar las hojas y archivos que selecciones. Esto puede incluir leer y actualizar Sheets, administrar pestañas, crear carpetas, subir, descargar, renombrar o eliminar archivos de Drive cuando uses esas funciones. No vendemos tus datos, no leemos archivos ajenos a la función del servicio ni usamos datos de Google para publicidad.

APIs públicas

Cuando creas una API y publicas o compartes una hoja para lectura, su identificador permite consultar los datos mediante la URL REST que aparece en el panel. No publiques información sensible: cualquier persona que conozca esa URL podrá leer los datos autorizados por la configuración de Google. LittleAPI no guarda tokens de Google en el catálogo público.

Almacenamiento y seguridad

La cuenta, los proyectos y las reglas de acceso se almacenan en Supabase. Cada usuario solo puede consultar sus propios proyectos. El navegador utiliza tokens OAuth temporales y no contiene claves secretas. Puedes retirar el acceso desde tu Cuenta de Google, eliminar una API o eliminar tus proyectos.

Contacto

Para consultas de privacidad, contacta al propietario del servicio a través del repositorio oficial de LittleAPI.
