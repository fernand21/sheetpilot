OVERVIEW

What the Excel add-in does

The add-in connects an Excel workbook to a LittleAPI API backed by Google Sheets. It is designed for people who prefer editing data with native Excel tools instead of sending individual POST, PATCH, or DELETE requests.

Qué hace el complemento para Excel

El complemento conecta un libro de Excel a una API de LittleAPI respaldada por Google Sheets. Está pensado para quienes prefieren editar los datos con las herramientas normales de Excel en lugar de enviar manualmente solicitudes POST, PATCH o DELETE.

Whole workbookLibro completo

It discovers every Google Sheets tab and creates or reuses local Excel worksheets.Detecta todas las pestañas de Google Sheets y crea o reutiliza hojas locales de Excel.

All columnsTodas las columnas

There is no display-column filter in the add-in. The full linked worksheet is loaded.No existe filtro de columnas en el complemento. Se carga la hoja vinculada completa.

Native Excel editingEdición nativa de Excel

Edit cells, add rows, or delete rows using normal Excel commands and synchronize afterward.Edita celdas, agrega filas o elimina filas con los comandos normales de Excel y luego sincroniza.

FIRST CONNECTION

Connect an Excel workbook to LittleAPI

You need the API ID and API key for the LittleAPI API that points to your Google Sheets workbook.

Conecta un libro de Excel a LittleAPI

Necesitas el API ID y la API key de la API de LittleAPI que apunta a tu libro de Google Sheets.

1

Install the add-inInstala el complemento

Download the ZIP above, extract it, run the installer, and then open Microsoft Excel.Descarga el ZIP, extráelo, ejecuta el instalador y después abre Microsoft Excel.

2

Configure API

Open the LittleAPI tab in the Excel Ribbon and choose Configure API. Paste the API ID or public endpoint, then paste the API key.Abre la pestaña LittleAPI de la cinta de Excel y pulsa Configure API. Pega el API ID o endpoint público y después la API key.

3

Test Connection

Choose Test Connection. A successful response confirms that the API ID and key are valid.Pulsa Test Connection. Una respuesta correcta confirma que el API ID y la clave son válidos.

4

Load Workbook

Choose Load Workbook. The add-in obtains the remote tab list and loads every worksheet.Pulsa Load Workbook. El complemento obtiene la lista de pestañas remotas y carga todas las hojas.

5

Edit normallyEdita normalmente

Use filters, sorting and normal Excel editing. Synchronization sends cell values, not the Excel formulas themselves.Usa filtros, ordenación y edición normal de Excel. La sincronización envía los valores de las celdas, no las fórmulas de Excel.

6

Save / Synchronize

When ready, choose Save / Synchronize to send the current state of all linked worksheets back to Google Sheets.Cuando termines, pulsa Save / Synchronize para enviar el estado actual de todas las hojas vinculadas a Google Sheets.

Public endpoint formatFormato del endpoint públicohttps://littleapi.online/api/v1/{API_ID}

SYNCHRONIZATION

How synchronization behaves

The add-in treats each linked Excel worksheet as the current source for the corresponding Google Sheets tab at synchronization time.

Cómo funciona la sincronización

Al sincronizar, el complemento toma cada hoja de Excel vinculada como el estado actual de la pestaña correspondiente de Google Sheets.

Writes firstPrimero escribe

The current Excel values are written before any obsolete remote range is cleared. This reduces the risk of leaving a tab empty if a later cleanup fails.Los valores actuales de Excel se escriben antes de limpiar rangos remotos obsoletos. Así se reduce el riesgo de dejar una pestaña vacía si falla una limpieza posterior.

Only clears what became obsoleteSolo limpia lo que sobra

The add-in remembers the previous remote row and column bounds. If the worksheet did not become smaller, no CLEAR request is needed.El complemento recuerda los límites anteriores de filas y columnas. Si la hoja no se hizo más pequeña, no necesita ninguna operación CLEAR.

Linked sheets onlySolo hojas vinculadas

Normal local Excel sheets that were not created or linked by LittleAPI are ignored during synchronization.Las hojas locales normales que no fueron creadas o vinculadas por LittleAPI se ignoran durante la sincronización.

Example of the optimized cleanupEjemplo de limpieza optimizada

If Google previously contained 1,000 rows and 12 columns, but Excel now contains 700 rows and 12 columns, LittleAPI writes the current data and only clears A701:L1000.Si Google antes tenía 1.000 filas y 12 columnas, pero Excel ahora tiene 700 filas y 12 columnas, LittleAPI escribe los datos actuales y solo limpia A701:L1000.

PERSISTENCE

Does the workbook stay connected after closing Excel?

Yes. Save the Excel workbook normally and the LittleAPI connection metadata remains with it.

¿El libro sigue conectado después de cerrar Excel?

Sí. Guarda el libro de Excel normalmente y los metadatos de conexión de LittleAPI permanecen dentro del archivo.

API ID

The connected LittleAPI API identifier is stored at workbook level.El identificador de la API de LittleAPI se guarda a nivel del libro.

API key

The stored key allows the workbook to reconnect without asking again after every restart.La clave guardada permite que el libro se reconecte sin pedirla de nuevo en cada inicio.

Per-sheet linkVínculo por hoja

Each imported worksheet remembers its original Google Sheets tab name, even if the local Excel sheet is later renamed.Cada hoja importada recuerda el nombre original de su pestaña de Google Sheets incluso si luego renombras la hoja local de Excel.

Use an Excel workbook formatUsa un formato de libro de Excel

Save as XLSX or XLSM. A CSV file cannot preserve workbook-level connection metadata or multiple worksheets.Guarda como XLSX o XLSM. Un archivo CSV no puede conservar los metadatos de conexión del libro ni múltiples hojas.

SECURITY

Important API key note

The current add-in stores its API key in the Excel workbook so the connection can survive closing and reopening Excel.

Nota importante sobre la API key

La versión actual del complemento guarda la API key dentro del libro de Excel para que la conexión sobreviva al cerrar y volver a abrir Excel.

Do not treat a connected workbook as a public file.No trates un libro conectado como un archivo público.

Anyone who receives a workbook should be considered able to access its stored connection metadata. For workbooks you plan to share, use a dedicated additional LittleAPI key with only the permissions that workbook needs, so it can be revoked independently.Debes considerar que quien reciba el libro puede acceder a sus metadatos de conexión. Para libros que vayas a compartir, usa una clave adicional de LittleAPI dedicada y con solo los permisos necesarios, de modo que puedas revocarla de forma independiente.
