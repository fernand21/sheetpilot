CREATE THE WIDGET

From View endpoint to iframe

1
Open View endpoint

Open the API you already published from the LittleAPI dashboard.

2
Enable public read

The embeddable widget is public by design. Read permission and Public read must be enabled.

3
Choose sheet and columns

LittleAPI reads workbook tabs and the first-row headers so you can select fields by name.

4
Copy the iframe

Paste the generated code in WordPress, GitHub Pages, WebBuilder or any page that accepts HTML iframes.

<iframe
  src="https://littleapi.online/embed.html?api=YOUR_API_ID&sheet=Cartera&col=D&col=B&col=C&page_size=25&lang=es&title=Cartera"
  title="Cartera"
  loading="lazy"
  style="width:100%;height:520px;border:0;border-radius:16px;overflow:hidden"
  referrerpolicy="strict-origin-when-cross-origin">
</iframe>

SHEET + FIELDS

Show only what your visitor should see

SHEET

Choose a workbook tab

The generator lists the Google Sheets tabs available in the connected workbook.

COLUMNS

Choose visible columns

If the sheet contains ID, Date, Value, Name, you can publish only Name, Date and Value.

ORDER

Reorder without changing Sheets

Use the up/down controls to publish Name, Date, Value even if the physical sheet order is ID, Date, Value, Name.

Sheet: ID | Date | Value | Name
Widget: Name | Date | Value

The generated iframe stores Google column letters internally. Visitors do not need to know or use those letters.

LARGE SHEETS

Pagination that stays lightweight

Rows per page is numeric and defaults to 25. You can choose another value up to 100. The widget requests only the block it needs instead of downloading the entire sheet.

25

Rows per page

Set 10, 25, 50 or another number. New widgets use 25 by default.

1 / 12

Current page / total pages

The widget calculates the total and shows Page 1 of 12, Page 4 of 12, and so on.

30 ↵

Jump directly

Type page 30 and press Enter instead of clicking Next twenty-nine times.

page_size=25

Previous   Page [ 4 ] of 12   Next

For normal browsing, LittleAPI uses LIMIT + OFFSET and asks for only one extra row when it needs to know whether another page exists.

WHOLE-SHEET SEARCH

Search beyond the current page

The search box is not a browser-only filter. It scans the whole selected sheet progressively, so a match on row 800 or row 5,000 can still appear even when the visitor started on page 1.

GLOBAL

Scans the selected sheet

Search checks the fields being queried for the widget, not just the 25 rows currently visible.

200

Progressive batches

Search reads blocks progressively instead of asking the Edge Function to hold the full sheet in memory.

25

Search results stay paginated

If a term has many matches, the results continue in pages using the same navigation.

colSelected column; repeated in display order.col=D&col=B&col=C
page_sizeRows shown on each page.page_size=25
viewTable or cards.view=table
themeAuto, dark or light.theme=auto

titleVisible widget title.title=Cartera

SECURITY

The iframe never contains your private API key

Embeddable widgets require Public read.

LittleAPI does not place X-API-Key inside the iframe. Keep write access, Drive operations and private reads behind API keys and the permission controls in View endpoint.

READ

Public widget

Use it for information you intentionally want visitors to read.

KEYS

Additional API keys

Create separate keys for Postman, apps or automations and give each one only the permissions it needs.

403

Permission enforcement

A key without a required operation should receive permission_denied instead of silently gaining access.

NEXT

Use the widget and REST API together

The widget is the fast display layer. The REST API remains available for JavaScript, Python, Postman, mobile apps and automations.
