SHEETPILOT · DOCUMENTACIÓN DE API

Convierte una hoja en una URL JSON.

SheetPilot sigue el modelo de SheetDB: conectas un libro, creas un identificador de API y consumes sus filas desde cualquier lenguaje con una petición HTTP.

Estado actual API REST activa

La Edge Function está desplegada en Supabase. Las lecturas, búsquedas, claves, nombre, conteo y celdas ya responden por URL. La hoja debe estar publicada o compartida como “cualquiera con el enlace puede ver”.

Modelo tipo SheetDB

Al pulsar Crear API en un proyecto se genera un identificador único. La URL final tiene este formato:

https://dnwaapropjmoyqxquzvs.supabase.co/functions/v1/sheetpilot-api/{API_ID}

Por ejemplo, si el identificador fuese abc123XYZ789:

curl "https://dnwaapropjmoyqxquzvs.supabase.co/functions/v1/sheetpilot-api/abc123XYZ789"

// Respuesta
[
  { "id": "1", "nombre": "Ana", "estado": "ACTIVO" }
]

El identificador es la dirección pública de lectura. La clave de administración se genera y se muestra una sola vez para futuras operaciones protegidas.

La interfaz también conserva las operaciones inspiradas en Gsheetsplus: GetSheet, GetSheetDataByColumnValue, FindCells, FindIds, UpdateSheet_cell, UpdateSheet_range, insert_list, delete_range, AddNewSheet, SetRangeFormat, GetSumByHeader, GetCountByHeader, GetCountIfByHeader y las funciones de Drive.

Inicio rápido

  1. En Supabase ejecuta supabase-schema.sql y después supabase-api-schema.sql.
  2. Abre la aplicación y entra únicamente con Google.
  3. En modo de pruebas, usa una cuenta incluida en Google Cloud → Google Auth Platform → Audience → Test users.
  4. Acepta los permisos de Google Sheets y Google Drive.
  5. En el panel pulsa Nuevo proyecto y elige un libro.
  6. Pulsa Crear API, guarda la clave mostrada y copia el endpoint.
  7. Para lectura pública, publica la hoja o comparte el libro como lector.
Importante: si cambias el nombre de la pestaña después de crear la API, vuelve a abrirla desde el panel para actualizar el proyecto.

Endpoints REST tipo SheetDB

La Edge Function usa la primera fila como nombres de propiedades. El parámetro sheet permite elegir otra pestaña del mismo libro.

Método y rutaDescripciónEjemplo
GET /{API_ID}Todas las filas como objetos JSON.?limit=10&offset=20
GET /{API_ID}/searchCoinciden todas las condiciones.?estado=ACTIVO
GET /{API_ID}/search_orCoincide al menos una condición.?estado=ACTIVO&estado=PENDIENTE
GET /{API_ID}/keysDevuelve los nombres de columnas..../keys
GET /{API_ID}/nameDevuelve el nombre de la API..../name
GET /{API_ID}/countCuenta filas sin encabezado..../count
GET /{API_ID}/cells/A1,B2Lee celdas concretas..../cells/A1,B2
POST, PATCH, DELETERutas reservadas para CRUD público con clave.Se habilitarán con OAuth de servidor.

Filtros y opciones

limit, offset, sort_by, sort_order=asc|desc|random, cast_numbers=edad,total, single_object=true, casesensitive=true y sheet=Nombre.

Las búsquedas admiten igualdad, exclusión con !, comodín * y operadores numéricos >, <, >= y <=.

APIs de Google Drive

El panel ya gestiona Drive mediante OAuth del propietario: listar, buscar, crear carpetas, subir, descargar, renombrar, eliminar y consultar cuota.

Acción del panelEndpoint oficial usadoEquivalente Gsheetsplus
Listar archivos y carpetasGET https://www.googleapis.com/drive/v3/filesShowFilesByFolderId, ShowFilesByFolderName
Crear carpetaPOST https://www.googleapis.com/drive/v3/filesCreateFolder, CreateFolderIfNotExist
Renombrar o eliminarPATCH/DELETE /drive/v3/files/{id}RenameFile, DeleteFile
Subir archivoPOST /upload/drive/v3/files?uploadType=multipartUploadFile
CuotaGET /drive/v3/about?fields=storageQuotaGetStorageQuota
API pública de Drive: un endpoint anónimo no debe guardar un token de Drive en el navegador. Se añadirá con OAuth de servidor y permisos por archivo/carpeta; mientras tanto estas operaciones funcionan de forma segura desde el panel del propietario.

Ejemplos de integración

JavaScript

const rows = await fetch(`${API}?limit=20&sort_by=nombre`).then(r => r.json());

Seguridad y permisos

  • La Edge Function no contiene una clave service_role en el repositorio.
  • La tabla privada de APIs usa RLS: cada usuario solo administra sus propios registros.
  • El catálogo público solo expone el identificador y la fuente marcada para lectura pública; nunca expone hashes ni tokens.
  • La clave de API de administración se guarda como hash y solo se muestra durante la creación.
  • Para producción habrá que completar la verificación de marca y acceso a datos de Google, además de configurar OAuth de servidor para mantener refresh tokens cifrados.

Límites y siguiente etapa

Ya disponible: URL REST real para leer y buscar hojas públicas, metadatos, paginación, orden, conteo y celdas. En el panel: CRUD completo para el propietario mediante su sesión Google.

Siguiente versión: OAuth de servidor con refresh tokens cifrados, POST/PATCH/DELETE desde la URL pública, API pública de Drive, límites por plan, caché, OpenAPI y dominio personalizado. No se marca como terminado hasta que el almacenamiento de credenciales y la rotación de claves estén configurados.
