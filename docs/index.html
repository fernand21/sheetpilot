LITTLEAPI · DOCUMENTACIÓN OFICIAL

Conecta cualquier aplicación con tu hoja.

LittleAPI convierte Google Sheets y Drive en APIs REST con una URL estable. Lee datos públicos desde cualquier lenguaje y protege las operaciones que cambian información con X-API-Key.

La URL base de todas las APIs 
https://littleapi.online/api/v1/YOUR_API_ID

Reemplaza YOUR_API_ID por el identificador que aparece en tu panel. No copies un ID de ejemplo como si fuera tuyo: cada API tiene su propia URL.

GETLeer filas

Lectura pública opcional, con filtros y paginación.

POST · PATCH · DELETECambiar datos

Escrituras autenticadas con tu clave de administración.

OPENAPIContrato automático

Importa /openapi.json en Postman, Insomnia o Swagger.

429Cuota transparente

Cuando se agota, recibes used, limit, remaining y reset_at.

Primeros pasos en tres minutos

  1. Crea y publica tu API

    Inicia sesión, conecta un libro de Google Sheets o un recurso de Drive y pulsa Publicar. La aplicación genera un API ID y una clave para escrituras.

  2. Copia tu URL, no la de este ejemplo

    Tu endpoint empieza por https://littleapi.online/api/v1/YOUR_API_ID. El API ID se puede ver en el panel y en el catálogo que compartas.

  3. Prueba una lectura

    Si la lectura es pública, abre la URL en el navegador o usa el probador de esta página. Si es privada, añade X-API-Key.

const API = "https://littleapi.online/api/v1/YOUR_API_ID";
const response = await fetch(`${API}?limit=20`);
const payload = await response.json();
console.table(payload.data);

Probador interactivo

Envía una solicitud directamente desde tu navegador para validar una URL, un filtro o una escritura. La clave sólo vive en esta pestaña: no se guarda en LittleAPI ni en localStorage. Úsala únicamente con una API y un dominio de confianza.

La respuesta aparecerá aquí.

El probador respeta CORS. Una API privada requiere X-API-Key; nunca pegues una clave en una web pública o en código que se descargue a todos los visitantes.

No confundas API ID con API key

YOUR_API_ID identifica la API y puede aparecer en una URL pública. YOUR_API_KEY permite modificar datos; trátala como una contraseña y no la compartas en el frontend.

Lecturas, filtros y paginación

La primera fila de cada pestaña se interpreta como encabezado. Los nombres de las columnas se usan como propiedades JSON. La pestaña por defecto es la configurada al publicar; puedes elegir otra con sheet.

MétodoRutaDescripciónClave
GET/{API_ID}Lista filas con data, total, limit, offset y meta.Según public_read
GET/{API_ID}/searchFiltra con todas las condiciones y texto completo.Según public_read
GET/search_orFiltra cuando coincide cualquier condición.Según public_read
GET/keysDevuelve los encabezados.Según public_read
GET/countCuenta las filas de datos.Según public_read
GET/cells/A1,B2Lee celdas concretas por coordenada.Según public_read
GET/statsCalcula conteo, suma, promedio, mínimo y máximo.Según public_read

Parámetros más usados

const API = "https://littleapi.online/api/v1/YOUR_API_ID";

// Paginación y orden
GET `${API}?limit=20&offset=20&sort=name&order=asc`

// Cambiar de pestaña y conservar el formato de filas antiguo
GET `${API}?sheet=Orders&legacy=true`

// Buscar texto o comparar propiedades
GET `${API}/search?search=Acme&status=ACTIVE&amount=%3E100`

// Comodines, columnas numéricas y un solo objeto
GET `${API}/search?name=Ana*&cast_numbers=amount&single_object=true`

// Agrupar y calcular
GET `${API}?group_by=status&count=id&sum=amount&avg=amount`

Los filtros aceptan igualdad, !valor para negar, >, <, >=, <= y * como comodín. Repite un parámetro con [] cuando necesites varias opciones.

Crear, actualizar y eliminar filas

Todas las mutaciones requieren X-API-Key y respetan los permisos de la API. Los objetos usan exactamente los nombres de la primera fila de la pestaña.

POST · insertar

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"data":{"id":"42","name":"Ana","status":"ACTIVE"}}'

PATCH · actualizar

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"},"data":{"status":"CLOSED"}}'

DELETE · eliminar

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"}}'
Escrituras permanentes

Prueba primero con una copia de tu hoja. Un DELETE puede retirar varias filas si el filtro coincide con más de una.

Administrar pestañas de Sheets

Estas rutas modifican la estructura del libro y por eso siempre requieren la clave. Usa un nombre de pestaña o el ID que devuelva la API.

MétodoRutaCuerpo o resultado
GET/sheetsLista títulos, índices y dimensiones.
POST/sheets{"name":"Orders 2026"}
PATCH/sheets/YOUR_SHEET{"name":"Archive"}
DELETE/sheets/YOUR_SHEETSin cuerpo.
POST/sheets/copy{"sheet":"YOUR_SHEET","destination_spreadsheet_id":"YOUR_SPREADSHEET_ID"}
curl -X POST "$API/sheets" \
  -H "X-API-Key: $LITTLEAPI_KEY" -H "Content-Type: application/json" \
  -d '{"name":"Orders 2026"}'

Rangos, formato, lotes y exportación

Las herramientas usan el mismo endpoint y la misma clave. Las solicitudes de lote siguen el formato de Google Sheets batchUpdate y aceptan hasta 50 operaciones.

# Limpiar un rango
curl -X POST "$API/clear" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"YOUR_SHEET","range":"H2:Z1000"}'

# Dar formato al encabezado
curl -X POST "$API/format" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"YOUR_SHEET","range":"A1:G1","bold":true,"bgColor":"#087a70","textColor":"#ffffff","horizontalAlignment":"CENTER"}'

# Ejecutar cambios atómicos
curl -X POST "$API/batch" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"requests":[{"addSheet":{"properties":{"title":"Import"}}}]}'

# Descargar CSV o Excel
curl -L "$API/export.csv?sheet=YOUR_SHEET" -o export.csv
curl -L "$API/export.xlsx" -H "X-API-Key: $LITTLEAPI_KEY" -o workbook.xlsx

APIs de Google Drive

Publica un recurso de Drive para usar archivos y carpetas desde una URL REST. Drive siempre exige X-API-Key porque las rutas pueden crear, renombrar o borrar archivos.

MétodoRutaUso
GET/{API_ID}Metadatos del recurso raíz.
GET/children/YOUR_FOLDER_IDLista archivos de una carpeta.
GET/search?name=report&parent_id=YOUR_FOLDER_IDBusca por nombre y carpeta.
GET/download/YOUR_FILE_IDDescarga el archivo.
GET/quotaMuestra la cuota de almacenamiento.
POST/YOUR_FOLDER_IDCrea una carpeta o sube base64.
PATCH/YOUR_FILE_IDRenombra un archivo.
DELETE/YOUR_FILE_IDElimina o envía a la papelera.
curl "$DRIVE_API/search?name=report&parent_id=YOUR_FOLDER_ID" \
  -H "X-API-Key: $LITTLEAPI_KEY"

curl -X POST "$DRIVE_API/YOUR_FOLDER_ID" \
  -H "X-API-Key: $LITTLEAPI_KEY" -H "Content-Type: application/json" \
  -d '{"name":"hello.txt","mimeType":"text/plain","content_base64":"SG9sYSBMaXR0bGVBUEk="}'

Ejemplos desde cualquier lenguaje

JavaScript / TypeScript

const API = "https://littleapi.online/api/v1/YOUR_API_ID";
const KEY = "sp_live_YOUR_API_KEY";

const rows = await fetch(`${API}?limit=50`).then(async (response) => {
  if (!response.ok) throw new Error(await response.text());
  return response.json();
});
console.table(rows.data);

await fetch(API, {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-API-Key": KEY },
  body: JSON.stringify({ data: { id: "42", name: "Ana" } })
});

Respuestas y errores

Las respuestas JSON mantienen una forma predecible para que tu aplicación pueda manejar éxito y error sin analizar texto libre.

// GET /{API_ID}?limit=2
{
  "data": [{ "id": "42", "name": "Ana", "status": "ACTIVE" }],
  "total": 1,
  "limit": 2,
  "offset": 0,
  "meta": { "api_id": "YOUR_API_ID", "name": "YOUR_API_NAME", "sheet": "YOUR_SHEET" }
}

// Error de autenticación
{ "error": "api_key_required", "message": "Las operaciones de escritura requieren la cabecera X-API-Key." }
HTTPCódigoQué revisar
400invalid_*Cuerpo, rango, filtro o parámetro.
401api_key_requiredPublica la lectura o envía X-API-Key.
403permission_deniedActiva ese permiso en la configuración.
404api_not_found / sheet_not_foundComprueba API ID, pestaña o recurso.
429quota_exceededEspera reset_at o reduce el volumen.
502upstream_errorRevisa permisos de Google y disponibilidad de Sheets/Drive.

Cada API también expone /openapi.json para generar clientes y probar rutas desde herramientas compatibles.

Cuotas mensuales

El límite se aplica por API y se reinicia el primer día de cada mes UTC. El plan y la cuenta determinan el valor configurado; una cuenta autorizada puede tener una cuota personalizada o ilimitada.

# Consultar consumo (requiere la clave del propietario)
curl "https://littleapi.online/api/v1/YOUR_API_ID/usage" \
  -H "X-API-Key: sp_live_YOUR_API_KEY"

// Cuenta con cuota normal
{ "api_id": "YOUR_API_ID", "quota": {
  "used": 124, "limit": 5000, "remaining": 4876,
  "reset_at": "2026-10-01T00:00:00.000Z"
} }

// Cuenta autorizada sin límite de LittleAPI
{ "api_id": "YOUR_API_ID", "quota": {
  "used": 124, "limit": null, "remaining": null,
  "reset_at": null, "unlimited": true
} }
Cuando se agota

LittleAPI responde HTTP 429 con quota_exceeded y la fecha reset_at. Las cuotas propias de Google Sheets y Drive siguen aplicando aunque tu cuota de LittleAPI sea personalizada.

Seguridad y publicación

  • Publica sólo las pestañas que realmente quieras exponer.
  • Guarda X-API-Key en variables de entorno o en el servidor, nunca en el navegador de tus clientes.
  • Si una clave se filtra, regénérala desde el panel y reemplázala en tus aplicaciones.
  • Usa paginación, filtros y caché para no pedir miles de filas repetidamente.
  • El consumidor de una lectura pública no necesita cuenta de LittleAPI.
Nunca expongas la clave en frontend

El probador es útil para desarrollo. En producción, las escrituras deben salir de tu backend o de un entorno seguro.

Preguntas frecuentes

¿Necesito iniciar sesión para leer?

No, si el propietario activó public_read. Las lecturas privadas requieren X-API-Key.

¿Puedo cambiar de pestaña?

Sí. Añade ?sheet=NombreDePestana a una lectura o incluye sheet en el cuerpo de una escritura.

¿Qué pasa si Google revoca el acceso?

La API devolverá upstream_error. El propietario debe conectar Google otra vez y comprobar los permisos del libro o recurso.

¿Cómo genero un cliente?

Abre /openapi.json, copia el contrato e impórtalo en Postman, Insomnia, Swagger UI o un generador OpenAPI.
