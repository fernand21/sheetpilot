GOOGLE SHEETS + GOOGLE DRIVE

Documentation written for people, not only programmers.

This page only covers the public Google Sheets and Google Drive capabilities. Every function shows a complete URL and a copy-ready example. You do not need to learn variables such as $API or $KEY.

Example Sheets API
https://littleapi.online/api/v1/YOUR_API_ID

Replace YOUR_API_ID with the ID shown in your LittleAPI dashboard.

BEFORE YOU START

Three things you will see in the examples

YOUR_API_IDThe identifier of your Google Sheets API.
YOUR_DRIVE_API_IDThe identifier of an API configured for Google Drive.
your apikeyYour private key. When required it is sent as X-API-Key.
Example with a key
curl "https://littleapi.online/api/v1/YOUR_API_ID/usage" \
  -H "X-API-Key: your apikey"

JSON

Large datasets remain one single array

Firefox may show [0…99], [100…199] and other groups. That is only a browser display aid. LittleAPI still returns one single data[] array.

{
  "data": [{"id":"1","name":"Ana"}],
  "total": 421,
  "limit": 100,
  "offset": 0,
  "returned": 100,
  "has_more": true,
  "next_offset": 100,
  "max_limit": 1000
}
If you only want the array
https://littleapi.online/api/v1/YOUR_API_ID?raw=true
legacy=true also works for compatibility.

SECURITY

Simple rules

X-API-Key

Never put a real key in a public URL.

public_read

Only publish sheets whose data may safely be public.

all:true

Use it only if you intend to change or delete every row.
