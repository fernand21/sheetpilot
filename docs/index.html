LITTLEAPI · DEVELOPER DOCUMENTATION

Your sheet has the data. Give it an API.

LittleAPI turns Google Sheets and Google Drive into REST endpoints with a stable URL, predictable JSON responses and protected operations using X-API-Key.

Base URL for an API
https://littleapi.online/api/v1/YOUR_API_ID

Every API has its own API ID and can also expose /openapi.json.

GETRead data

Filter, sort, paginate and switch sheets.

POST · PATCH · DELETEChange data

Writes use X-API-Key.

OPENAPIAutomatic contract

Import the contract into Postman or Swagger.

429Clear quotas

Receive used, limit, remaining and reset_at.

From a sheet to an endpoint in three steps

  1. Connect Google

    Sign in and authorize the Sheets and Drive features you want to use.

  2. Publish the API

    Choose a workbook and sheet. The dashboard generates an API ID and a key for protected operations.

  3. Consume JSON

    Use the endpoint from any language or HTTP client.

const API = "https://littleapi.online/api/v1/YOUR_API_ID";
const response = await fetch(`${API}?limit=20`);
const payload = await response.json();
console.table(payload.data);

API ID is not the API key

The API ID may appear in a public URL. The API key can modify data and must stay in a secure environment.

Reads, filters and pagination

The first row is treated as the header and every column becomes a JSON property.

MethodPathUse
GET/{API_ID}List rows with pagination.
GET/{API_ID}/searchFilters and search.
GET/search_orMatch any condition.
GET/keysHeaders.
GET/countRow count.
GET/cells/A1,B2Specific cells.
GET/statsSum, average, minimum and maximum.
GET ${API}?limit=20&offset=20&sort=name&order=asc
GET ${API}?sheet=Orders&legacy=true
GET ${API}/search?search=Acme&status=ACTIVE&amount=%3E100
GET ${API}?group_by=status&count=id&sum=amount&avg=amount

Create, update and delete rows

All mutations require X-API-Key and respect API permissions.

# Create
curl -X POST "$API" -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"data":{"id":"42","name":"Ana","status":"ACTIVE"}}'

# Update
curl -X PATCH "$API" -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"},"data":{"status":"CLOSED"}}'

# Delete
curl -X DELETE "$API" -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"}}'
Writes change the real sheet

Test on a copy before running destructive operations.

Google Drive APIs

Drive always requires X-API-Key because its routes can create, rename, download or delete files.

MethodPathUse
GET/children/YOUR_FOLDER_IDList folder.
GET/search?name=reportSearch by name.
GET/download/YOUR_FILE_IDDownload file.
GET/quotaRead storage quota.
POST/YOUR_FOLDER_IDCreate folder or upload base64.
PATCH/YOUR_FILE_IDRename.
DELETE/YOUR_FILE_IDDelete or trash.

Code examples

JavaScript

const rows = await fetch("https://littleapi.online/api/v1/YOUR_API_ID?limit=50")
  .then(r => r.json());
console.table(rows.data);

Python

rows = requests.get("https://littleapi.online/api/v1/YOUR_API_ID", params={"limit": 50}).json()["data"]

$rows = json_decode(file_get_contents($api . '?limit=20'), true);

Monthly quotas

Quota applies per API and resets on the first day of each UTC month. Google provider quotas still apply.

curl "$API/usage" -H "X-API-Key: $KEY"

{"quota":{"used":124,"limit":5000,"remaining":4876,
"reset_at":"2026-10-01T00:00:00.000Z"}}

Security

  • Publish only the sheets you intend to expose.
  • Store X-API-Key in environment variables or on the backend.
  • Regenerate a key if it leaks.
  • Use pagination, filters and cache to reduce calls.
Never expose a write key in frontend code

Production writes should originate from a backend or secure environment.
