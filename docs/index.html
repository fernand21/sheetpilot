LITTLEAPI · DEVELOPER DOCUMENTATION

Your sheet has the data. Give it an API.

LittleAPI turns Google Sheets and Google Drive into REST endpoints with a stable URL, predictable JSON responses and protected operations using X-API-Key.

Base URL for an API
https://littleapi.online/api/v1/YOUR_API_ID

YOUR_API_ID identifies the published API. Every API has its own ID and can also expose /openapi.json.

GETRead data

Filter, sort, paginate and switch sheets.

POST · PATCH · DELETEChange data

Writes use X-API-Key and respect permissions.

OPENAPIAutomatic contract

Import the contract into Postman, Insomnia or Swagger.

429Transparent quotas

Responses expose used, limit, remaining and reset_at.

From a sheet to an endpoint in three steps

  1. Connect Google

    Sign in to LittleAPI and authorize the Sheets and Drive features you want to use.

  2. Publish the API

    Choose the workbook and sheet. The dashboard generates an API ID and, for writes, an administration key.

  3. Consume JSON

    Use the URL from JavaScript, Python, PHP, automations or any HTTP client.

const API = "https://littleapi.online/api/v1/YOUR_API_ID";
const response = await fetch(`${API}?limit=20`);
const payload = await response.json();
console.table(payload.data);

API ID is not the API key

The API ID may appear in a public URL. The API key can modify data; treat it like a password and never expose it in frontend code.

Reads, filters and pagination

The first row of a sheet is used as the header and each column name becomes a JSON property.

MethodPathUse
GET/{API_ID}List rows with pagination and metadata.
GET/{API_ID}/searchFilter with conditions and full-text search.
GET/search_orMatch any of several conditions.
GET/keysReturn headers.
GET/countCount rows.
GET/cells/A1,B2Read specific cells.
GET/statsCount, sum, average, minimum and maximum.
GET ${API}?limit=20&offset=20&sort=name&order=asc
GET ${API}?sheet=Orders&legacy=true
GET ${API}/search?search=Acme&status=ACTIVE&amount=%3E100
GET ${API}?group_by=status&count=id&sum=amount&avg=amount

Filters support equality, negation with !, comparison operators > < >= <= and * as a wildcard.

Create, update and delete rows

All mutations require X-API-Key and respect the permissions configured for the API.

POST · create

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"data":{"id":"42","name":"Ana","status":"ACTIVE"}}'

PATCH · update

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"},"data":{"status":"CLOSED"}}'

DELETE

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: sp_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"id":"42"}}'
Writes change the real sheet

Test destructive operations on a copy first. A DELETE may remove multiple rows if the filter matches more than one.

Monthly quotas

Limits apply per API and reset on the first day of each UTC month. Google Sheets and Drive provider quotas still apply.

curl "https://littleapi.online/api/v1/YOUR_API_ID/usage" \
  -H "X-API-Key: sp_live_YOUR_API_KEY"

{
  "quota": { "used": 124, "limit": 5000, "remaining": 4876,
             "reset_at": "2026-10-01T00:00:00.000Z" }
}
HTTP 429

When a quota is exhausted, LittleAPI returns quota_exceeded together with reset_at.

Security and publishing

  • Publish only the sheets you actually want to expose.
  • Store X-API-Key in environment variables or on your backend.
  • If a key leaks, regenerate it from the dashboard.
  • Use pagination, filters and cache to avoid unnecessary reads.
Never expose a write key in frontend code

In production, writes should originate from a backend or another secure environment.
