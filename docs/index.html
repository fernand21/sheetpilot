RESPONSE

One array, even with hundreds of records

LittleAPI does not split data into 100-row chunks. Firefox and other viewers may display [0…99], [100…199], etc. only as a visual grouping of the JSON tree. A parser receives one single array.

Normal response

{
  "data":[{"id":"1","name":"Ana"}],
  "total":421,
  "limit":100,
  "offset":0,
  "returned":100,
  "has_more":true,
  "next_offset":100,
  "max_limit":1000,
  "meta":{"api_id":"YOUR_API_ID","name":"Customers","sheet":"Sheet1"}
}

Data only

GET /YOUR_API_ID?raw=true

[
  {"id":"1","name":"Ana"},
  {"id":"2","name":"Luis"}
]

legacy=true remains a compatible alias for raw=true.

For direct analysis
Use /export.json to download a JSON file and avoid depending on the browser viewer.

READS

Read, paginate, sort and transform

The first Sheets row becomes the JSON property names. Duplicate headers receive _2, _3, etc.

FILTERS

AND/OR search, comparisons and wildcards

/search combines column conditions with AND. /search_or accepts a row when any condition matches. search looks for text in any column.

ANALYTICS

Group, count, sum, average, minimum and maximum

group_by, count, sum, avg, min and max can be combined. sum/avg/min/max accept comma-separated or repeated fields. On /search, filtering happens before aggregation.

HELPERS

Columns, cells, statistics and metadata

EXPORT

JSON, CSV and Excel

JSON can use read parameters. CSV exports one sheet and XLSX exports the full workbook.

CRUD

Insert, update and delete rows

All writes require X-API-Key and the corresponding permission. Properties must match first-row headers.

v1.2 safety
PATCH and DELETE no longer affect every row accidentally when where is omitted. You must send where/match or explicit all:true.

SHEET TABS

Manage workbook structure

All of these routes require a key. The last remaining sheet cannot be deleted.

TOOLS

Formatting, clearing and batchUpdate

/format accepts A1 notation or gridRange. /batch accepts 1 to 50 Google Sheets batchUpdate requests.

GOOGLE DRIVE

Files and folders over REST

Every Drive route requires X-API-Key in v1.2. Listings support page_size, page_token and order_by; native Google files are exported with /export/{file_id}.

OWNER / DASHBOARD

Google connection and secure key recovery

These routes are intended for the dashboard. They use the owner's Supabase session JWT in Authorization, not X-API-Key. Refresh tokens and recoverable keys are encrypted on the server.

Never publish a real JWT, refresh token or API key.

Pagination, usage and headers

Counts

Data reads, searches, stats, exports, writes and Drive.

Does not count

/health, /name, /metadata, /openapi.json, /usage.

Reset

First day of each UTC month.

Max page

1,000 rows; continue with next_offset.

Recommended pagination

let offset = 0;
const allRows = [];
while (true) {
  const page = await fetch(`${API}?limit=1000&offset=${offset}`).then(r => r.json());
  allRows.push(...page.data);
  if (!page.has_more) break;
  offset = page.next_offset;
}

Cache

Public reads with cache_ttl > 0 may return X-LittleAPI-Cache: MISS/HIT. Effective TTL is capped at 3,600 s. Writes clear the function cache.

CLIENTS

Language examples

JavaScript / TypeScript

const API = "https://littleapi.online/api/v1/YOUR_API_ID";
const page = await fetch(`${API}?limit=100&select=id,name,status`).then(r => r.json());
console.table(page.data);
console.log(page.next_offset);

Python

import requests
API = "https://littleapi.online/api/v1/YOUR_API_ID"
page = requests.get(API, params={"limit":100,"select":"id,name,status"}).json()
print(page["data"], page["next_offset"])

PHP

<?php
$api = "https://littleapi.online/api/v1/YOUR_API_ID";
$page = json_decode(file_get_contents($api . "?limit=100&select=id,name,status"), true);

?>

B4J / Java

Dim j As HttpJob
j.Initialize("", Me)
j.Download("https://littleapi.online/api/v1/YOUR_API_ID?limit=100")
Wait For (j) JobDone(j As HttpJob)
If j.Success Then
    Dim parser As JSONParser
    parser.Initialize(j.GetString)
    Dim result As Map = parser.NextObject
    Dim rows As List = result.Get("data")
    Log(rows.Size)
End If
j.Release

SECURITY

Production rules

X-API-Key

Keep it in a backend or environment variable; never in URLs or public frontend code.

public_read

Enable it only for sheets that may be read by anyone with the URL.

Permissions

read, search, create, update, delete.

Drive

Every route requires X-API-Key in v1.2.

all:true

It is explicit to reduce accidental bulk changes.

Encryption

Google refresh tokens and recoverable API keys are encrypted server-side.

CORS / OPTIONS

curl -i -X OPTIONS "$API" \
  -H "Origin: https://example.com" \
  -H "Access-Control-Request-Method: GET"

LittleAPI returns 204 to preflight and supports GET, POST, PATCH, DELETE and OPTIONS.
