SHEETPILOT · DOCUMENTACIÓN

De una hoja de cálculo a operaciones reutilizables.

SheetPilot conecta tu cuenta de Google, muestra tus libros y permite consultar, modificar, formatear y administrar Sheets y Drive desde una página estática.

Estado actual En pruebas

La aplicación funciona en GitHub Pages y usa Supabase Auth para la sesión. Las llamadas a Google se realizan con un token OAuth del usuario, sin guardar claves secretas en el navegador.

Inicio rápido

  1. Abre la aplicación y pulsa Continuar con Google.
  2. En modo de pruebas, usa una cuenta incluida en Google Cloud → Audience → Test users.
  3. Acepta los permisos de Sheets y Drive.
  4. En el panel pulsa Nuevo proyecto y elige un libro.
  5. Abre el espacio del proyecto para trabajar con Datos, Editar, Pestañas, Formato, Consultas o Estadísticas.
Primera configuración: en Supabase ejecuta supabase-schema.sql desde SQL Editor. Si aparece permission denied for table projects, faltan los grants de la Data API.

Ejemplos de integración

Leer una hoja desde JavaScript

const spreadsheetId = "TU_ID";
const range = encodeURIComponent("'Clientes'!A1:Z200");
const response = await fetch(
  "https://sheets.googleapis.com/v4/spreadsheets/" +
  spreadsheetId + "/values/" + range,
  { headers: { Authorization: "Bearer " + accessToken } }
);
const data = await response.json();
console.log(data.values);

Actualizar una celda

await fetch(
  "https://sheets.googleapis.com/v4/spreadsheets/" +
  spreadsheetId + "/values/" + encodeURIComponent("'Clientes'!B2") +
  "?valueInputOption=USER_ENTERED",
  {
    method: "PUT",
    headers: {
      Authorization: "Bearer " + accessToken,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      range: "'Clientes'!B2",
      majorDimension: "ROWS",
      values: [["Activo"]]
    })
  }
);

Filtro avanzado

En la pestaña Consultas puedes escribir, por ejemplo, Estado = 'ACTIVO' o una consulta completa como SELECT Producto, SUM(Total) GROUP BY Producto.

Seguridad y permisos

  • La clave publishable de Supabase puede estar en el navegador; nunca se publica una clave service_role.
  • Supabase RLS limita cada registro de projects a su propietario.
  • Google entrega un token OAuth temporal; SheetPilot no muestra ni solicita el client secret.
  • Los permisos de Drive son amplios porque las funciones de la biblioteca incluyen crear, subir, renombrar y eliminar archivos. En producción habrá que completar la verificación de Google y justificar esos scopes.
  • Revoca el acceso desde tu cuenta de Google cuando quieras.

Límites y siguiente etapa

Importante: GitHub Pages es estático. La aplicación actual ejecuta las operaciones con el token del usuario, pero todavía no expone una API pública anónima tipo /v1/clientes. Para eso se desplegará una Edge Function de Supabase que use una API key por proyecto y un almacenamiento seguro de credenciales/sincronización.

La siguiente etapa del producto será: claves de API por proyecto, endpoint público con documentación OpenAPI, sincronización segura y dominio personalizado. Así se conservará la URL real de la aplicación y se añadirá una URL estable para cada API.
