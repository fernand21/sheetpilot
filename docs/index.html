LITTLEAPI · API REST OFICIAL

Tu hoja se convierte en una API.

LittleAPI expone tus datos de Google Sheets y Drive con una URL estable. Lee desde cualquier sitio del mundo sin iniciar sesión y usa una clave para crear, actualizar, eliminar y automatizar.

La URL pública siempre tiene esta forma
https://littleapi.online/api/v1/{API_ID}

El API_ID aparece en tu panel al publicar una API. La cuenta del propietario sólo es necesaria para crearla y administrarla; tus consumidores usan HTTP.

La respuesta de filas tiene una envoltura consistente: data, total, limit, offset y meta.

Autenticación y respuestas

GET público
Si publicaste la lectura, no se requiere login ni clave.
X-API-Key
Las escrituras viajan desde cualquier aplicación con tu clave.
JSON
Los errores y operaciones responden con JSON descriptivo.
OpenAPI
Cada API publica su contrato en /openapi.json.
const API = "https://littleapi.online/api/v1/TU_API_ID";
const headers = { "X-API-Key": "sp_live_..." };

// Sólo el propietario ve la clave completa en el panel de LittleAPI.
// Nunca la pongas en una aplicación pública del navegador.
Clave de administración: LittleAPI la muestra al propietario autenticado y la guarda cifrada. Las lecturas públicas no la necesitan; protégela como una contraseña porque permite modificar la hoja.

Lecturas y consultas

La primera fila de la pestaña son los nombres de propiedades. La API usa la pestaña configurada al crearla; puedes cambiarla en una request con sheet.

Filtros, paginación y orden

# Página 2 de 20 filas, ordenada por LECTURA
curl "$API?limit=20&offset=20&sort=LECTURA&order=desc"

# Igualdad, negación, comparación numérica y comodines
curl "$API/search?MARCA=Honeywell&SACO=!0&LECTURA=%3E1000&SERIE=35*"

# Búsqueda de texto en todas las columnas
curl "$API/search?search=Honeywell"

# Buscar coincidencias en cualquier condición
curl "$API/search_or?MARCA=Honeywell&TIPO=2s"

# Convertir columnas numéricas y devolver un objeto
curl "$API?cast_numbers=LECTURA&single_object=true"

# Leer otra pestaña del mismo libro
curl "$API?sheet=Ventas&limit=50"

También puedes enviar una condición repetida como estado[]=NUEVO&estado[]=ACTIVO. Para preservar el formato antiguo de sólo filas usa legacy=true.

Crear, actualizar y eliminar

Todas las mutaciones funcionan sin login del consumidor. Sólo añade la clave en X-API-Key. Los objetos usan los nombres de la fila de encabezados.

Insertar filas · POST /{API_ID}

curl -X POST "$API" \
  -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"data":{"ITEM":"43","MARCA":"Honeywell","LECTURA":"3200"}}'

# Varias filas en una sola llamada
curl -X POST "$API" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"rows":[{"ITEM":"44","MARCA":"Acme"},{"ITEM":"45","MARCA":"Acme"}]}'

Actualizar filas · PATCH /{API_ID}

# Cambia todas las filas que cumplen where
curl -X PATCH "$API" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"ITEM":"43"},"data":{"LECTURA":"3500","SACO":"1"}}'

# Actualiza un rango directamente (matriz de valores)
curl -X PATCH "$API" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Medidores","range":"A2:C2","values":[["43","34800000","Acme"]]}'

Eliminar filas · DELETE /{API_ID}

curl -X DELETE "$API" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"where":{"ITEM":"43"}}'

Las condiciones aceptan igualdad, !, comodines con * y comparadores >, <, >= y <=.

Rangos, formato y automatización

Limpiar · POST /clear

curl -X POST "$API/clear" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" -d '{"sheet":"Medidores","range":"H2:Z1000"}'

Dar formato · POST /format

curl -X POST "$API/format" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Medidores","range":"A1:G1","bold":true,"bgColor":"#087a70","textColor":"#ffffff","horizontalAlignment":"CENTER"}'

Propiedades disponibles: bold, fontSize, textColor, bgColor y horizontalAlignment. También puedes indicar gridRange con índices de Google Sheets.

Lote atómico · POST /batch

curl -X POST "$API/batch" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"requests":[{"addSheet":{"properties":{"title":"Importación"}}},{"updateSpreadsheetProperties":{"properties":{"title":"Catálogo 2026"},"fields":"title"}}]}'

Envía de 1 a 50 objetos del formato spreadsheets.batchUpdate. Si Google rechaza uno, no se presenta el lote como aplicado.

Descargas

# CSV público de una pestaña
curl -L "$API/export.csv?sheet=Medidores" -o medidores.csv

# Libro Excel; requiere X-API-Key
curl -L "$API/export.xlsx" -H "X-API-Key: $LITTLEAPI_KEY" -o catalogo.xlsx

APIs de Drive

Al publicar un recurso de tipo Drive, la misma URL se convierte en una puerta REST para archivos y carpetas del Drive autorizado.

MétodoRutaUso
GET/{API_ID}Metadatos/listado del archivo raíz configurado.
GET/children/{FOLDER_ID}Lista archivos de una carpeta.
GET/search?name=informe&parent_id=IDBusca archivos por nombre y carpeta.
GET/quotaCuota de almacenamiento del propietario.
GET/aboutCuenta, cuota y formatos de importación/exportación.
GET/download/{FILE_ID}Descarga el contenido como archivo.
POST/{FOLDER_ID}Crea una carpeta/archivo o sube base64.
PATCH/{FILE_ID}Renombra un archivo.
DELETE/{FILE_ID}Mueve el archivo a la papelera/elimina.
# Buscar un archivo
curl "$DRIVE_API/search?name=presupuesto&parent_id=ID_CARPETA" -H "X-API-Key: $LITTLEAPI_KEY"

# Crear una carpeta
curl -X POST "$DRIVE_API/ID_PADRE" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" -d '{"name":"Reportes","mimeType":"application/vnd.google-apps.folder"}'

# Subir contenido base64
curl -X POST "$DRIVE_API/ID_CARPETA" -H "X-API-Key: $LITTLEAPI_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"saludo.txt","mimeType":"text/plain","content_base64":"SG9sYSBMaXR0bGVBUEk="}'

# Renombrar y borrar
curl -X PATCH "$DRIVE_API/ID_ARCHIVO" -H "X-API-Key: $LITTLEAPI_KEY" -H "Content-Type: application/json" -d '{"name":"final.txt"}'
curl -X DELETE "$DRIVE_API/ID_ARCHIVO" -H "X-API-Key: $LITTLEAPI_KEY"

Seguridad y publicación

  • El consumidor no necesita cuenta ni sesión de LittleAPI.
  • Activa lectura pública sólo para datos que realmente quieras exponer.
  • Usa X-API-Key para POST, PATCH, DELETE, formato, pestañas, Drive y exportación Excel.
  • La clave completa sólo aparece al propietario autenticado; nunca se incluye en el catálogo público ni en OpenAPI.
  • Si la clave se filtra, genera una nueva desde el panel y reemplázala en tus aplicaciones.
  • Google sigue aplicando sus cuotas de Sheets y Drive; usa paginación y evita pedir miles de filas en cada request.
Importante: no pongas una clave de escritura en JavaScript que se descargue al navegador de todos. Para una web pública usa un servidor intermedio o limita la API a operaciones de lectura.

Errores y diagnóstico

Los errores tienen siempre error y message. Ejemplo:

{ "error": "api_key_required", "message": "Las operaciones de escritura requieren la cabecera X-API-Key." }
HTTPCódigoSolución
400invalid_*Corrige el cuerpo, rango, nombre o parámetro indicado.
401api_key_requiredEnvía X-API-Key o publica la lectura.
403permission_deniedActiva ese permiso en la configuración de la API.
404api_not_found / sheet_not_foundComprueba el identificador y el nombre de pestaña.
502upstream_errorComprueba que la hoja siga compartida y que Google esté disponible.
