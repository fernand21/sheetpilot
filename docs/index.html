Pagination for large sheets

LittleAPI returns at most 1,000 rows per page. Use limit and offset when you want smaller pages.

SEARCH · FILTERS

Search and filter without writing SQL

These examples work directly in the URL. Column names are matched without caring about uppercase/lowercase unless casesensitive=true.

Search any column

https://littleapi.online/api/v1/YOUR_API_ID/search?search=Daniel

Exact value

https://littleapi.online/api/v1/YOUR_API_ID/search?Status=ACTIVE

Two conditions: AND

https://littleapi.online/api/v1/YOUR_API_ID/search?Status=ACTIVE&City=Quito

Different columns: OR

https://littleapi.online/api/v1/YOUR_API_ID/search_or?Status=ACTIVE&City=Quito

Text contains

https://littleapi.online/api/v1/YOUR_API_ID/search?contains[Name]=ana

Not equal

https://littleapi.online/api/v1/YOUR_API_ID/search?Status=!CANCELLED

Numeric / text comparisons

https://littleapi.online/api/v1/YOUR_API_ID/search?Total=%3E100 https://littleapi.online/api/v1/YOUR_API_ID/search?Age=%3E%3D18 https://littleapi.online/api/v1/YOUR_API_ID/search?Score=%3C50

Wildcard

https://littleapi.online/api/v1/YOUR_API_ID/search?Name=Ana*

Case-sensitive match

https://littleapi.online/api/v1/YOUR_API_ID/search?Name=ANA&casesensitive=true

Combine filter + sheet + select + sort + pagination

https://littleapi.online/api/v1/YOUR_API_ID/search?sheet=Sales&Status=ACTIVE&select=Name,Total&sort_by=Total&sort_order=desc&limit=50

PUBLIC API · ADVANCED QUERY

Advanced SELECT queries from the public API

Use /query to run Google Visualization queries through LittleAPI. Write your real sheet header names such as Name, Total or Date; LittleAPI translates them to Google column letters automatically.

The same query language now works from the dashboard and from the public REST API.

1. GET: easiest way to test a query

curl --get "https://littleapi.online/api/v1/YOUR_API_ID/query" \
  --data-urlencode "sheet=Sales" \
  --data-urlencode "q=SELECT Name, Total WHERE Total > 100 ORDER BY Total DESC LIMIT 20"

If Public Read is enabled, GET /query does not need an API key. For a private API, add -H "X-API-Key: your apikey".

2. Copy-ready query examples

SELECT * LIMIT 100 SELECT Name, Status WHERE Status = 'ACTIVE' SELECT * WHERE Name CONTAINS 'ana' SELECT Name, Total WHERE Total > 100 ORDER BY Total DESC SELECT Product, SUM(Total) GROUP BY Product SELECT Issue, COUNT(Issue) GROUP BY Issue SELECT Product, AVG(Total), MIN(Total), MAX(Total) GROUP BY Product SELECT Name, Date WHERE Date >= date '2026-01-01' ORDER BY Date SELECT Region, SUM(Total) GROUP BY Region PIVOT Year SELECT Product, SUM(Total) GROUP BY Product LABEL SUM(Total) 'Sales Total' SELECT * ORDER BY Date DESC LIMIT 50 OFFSET 50

3. POST: better for long queries

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/query" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","query":"SELECT Product, SUM(Total) GROUP BY Product"}'

For a private API, also add -H "X-API-Key: your apikey". POST /query is still read-only; it never writes to your sheet.

4. Query options

OptionPurposeExample
sheetChoose a tab.sheet=Archive
q / queryThe SELECT query.q=SELECT Name LIMIT 10
headersNumber of header rows, from 0 to 10.headers=1
columns=namesDefault: use human header names.SELECT Product, Total
columns=lettersAdvanced mode: write A, B, C directly.SELECT A, SUM(H) GROUP BY A
raw=trueReturn only the result array.?raw=true

5. Full URL example

https://littleapi.online/api/v1/YOUR_API_ID/query?sheet=Sales&q=SELECT%20Name%2C%20Total%20WHERE%20Total%20%3E%20100%20ORDER%20BY%20Total%20DESC%20LIMIT%2020

6. What the response tells you

{
  "data": [ ... ],
  "total": 20,
  "columns": ["Name", "Total"],
  "meta": {
    "sheet": "Sales",
    "query": "SELECT Name, Total WHERE Total > 100",
    "translated_query": "SELECT A, H WHERE H > 100",
    "header_rows": 1
  }
}

translated_query is useful for learning or debugging: it shows the Google column-letter query generated from your human header names. Use columns=letters only when you intentionally want to write A/B/C references yourself.

GOOGLE SHEETS · POST

Different ways to insert data

All write examples require the header X-API-Key: your apikey.

1. Insert one row using column names

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"Name":"Ana","Status":"ACTIVE","Total":125.50}'

2. Insert several rows at once

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"rows":[{"Name":"Ana","Status":"ACTIVE"},{"Name":"Luis","Status":"PENDING"}]}'

3. Insert rows by column position

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '[["Ana","ACTIVE",125.50],["Luis","PENDING",80]]'

4. Insert into another tab

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID?sheet=Archive" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"Name":"Ana","Status":"ARCHIVED"}'
When you send objects, LittleAPI follows the sheet header order automatically.

GOOGLE SHEETS · PATCH

Different ways to update data

1. Update an exact A1 range

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID?sheet=Sales" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"range":"B2:C3","values":[["ACTIVE",150],["PENDING",90]]}'

2. Update rows that match a value

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"ID":"42"},"data":{"Status":"DONE"}}'

3. Match several conditions

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"Status":"ACTIVE","City":"Quito"},"data":{"Reviewed":"YES"}}'

4. Update rows whose text contains a word

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"contains":{"Name":"ana"}},"data":{"Group":"A"}}'

5. Update every data row explicitly

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"all":true,"data":{"Reviewed":"NO"}}'
all:true is intentionally required for whole-sheet changes. LittleAPI will not update every row by accident.

DELETE + CLEAR

Delete rows or only clear cell contents

1. Delete rows with an exact match

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"ID":"42"}}'

2. Delete rows matching several conditions

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"Status":"CANCELLED","Year":"2025"}}'

3. Delete when a column contains text

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"contains":{"Notes":"duplicate"}}}'

4. Delete using a comparison

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"where":{"Total":"<0"}}'

5. Clear cells without deleting rows

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/clear" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","range":"B2:D100"}'

6. Delete every data row

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"all":true}'
DELETE removes complete sheet rows. /clear keeps the rows and only empties the chosen cells.

GOOGLE SHEETS · FORMAT

Different ways to format cells

Supported properties: bold, italic, underline, strikethrough, fontSize, textColor, bgColor, horizontalAlignment, verticalAlignment and wrapStrategy.

1. Style a header

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID/format" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","range":"A1:F1","bold":true,"fontSize":14,"bgColor":"#087a70","textColor":"#ffffff"}'

2. Italic, underline and alignment

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID/format" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","range":"A2:C20","italic":true,"underline":true,"horizontalAlignment":"CENTER","verticalAlignment":"MIDDLE"}'

3. Wrap text and change colors

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID/format" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","range":"D2:D200","wrapStrategy":"WRAP","bgColor":"#102a24","textColor":"#d8ff7d"}'

4. Advanced gridRange instead of A1

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID/format" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","gridRange":{"sheetId":0,"startRowIndex":0,"endRowIndex":1,"startColumnIndex":0,"endColumnIndex":6},"bold":true,"bgColor":"#087a70"}'

Use GET /sheets to discover the sheetId before using gridRange.

SHEET TABS

List, create, rename, delete and copy tabs

List tabs

curl "https://littleapi.online/api/v1/YOUR_API_ID/sheets" -H "X-API-Key: your apikey"

Create a tab

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/sheets" -H "X-API-Key: your apikey" -H "Content-Type: application/json" -d '{"name":"Archive 2026"}'

Rename a tab

curl -X PATCH "https://littleapi.online/api/v1/YOUR_API_ID/sheets/Archive%202026" -H "X-API-Key: your apikey" -H "Content-Type: application/json" -d '{"name":"Closed 2026"}'

Delete a tab

curl -X DELETE "https://littleapi.online/api/v1/YOUR_API_ID/sheets/Closed%202026" -H "X-API-Key: your apikey"

Copy a tab to another spreadsheet

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/sheets/copy" \
  -H "X-API-Key: your apikey" -H "Content-Type: application/json" \
  -d '{"sheet":"Sales","destination_spreadsheet_id":"DESTINATION_SPREADSHEET_ID"}'

ADVANCED

Batch

Send between 1 and 50 native Google Sheets batchUpdate requests in one LittleAPI call. Use this only when the simpler endpoints above do not cover your task.

Example: auto-resize columns A:F

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/batch" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"requests":[{"autoResizeDimensions":{"dimensions":{"sheetId":0,"dimension":"COLUMNS","startIndex":0,"endIndex":6}}}]}'

Example: freeze the first row

curl -X POST "https://littleapi.online/api/v1/YOUR_API_ID/batch" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"requests":[{"updateSheetProperties":{"properties":{"sheetId":0,"gridProperties":{"frozenRowCount":1}},"fields":"gridProperties.frozenRowCount"}}]}'

EXPORT

JSON, CSV and Excel

https://littleapi.online/api/v1/YOUR_API_ID/export.json?sheet=Sales https://littleapi.online/api/v1/YOUR_API_ID/export.csv?sheet=Sales

Excel export requires your API key:

curl "https://littleapi.online/api/v1/YOUR_API_ID/export.xlsx" \
  -H "X-API-Key: your apikey" \
  -o spreadsheet.xlsx
Firefox JSON viewer

If Firefox visually groups a large array as [0…99], [100…199], etc., the API did not split your JSON. That is only Firefox's viewer. Use raw=true or export.json when you want a simpler representation.

GOOGLE DRIVE · GET

Browse and search Drive

Drive endpoints require X-API-Key.

File or folder information

curl "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/FILE_ID" -H "X-API-Key: your apikey"

List folder children

curl "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/children/FOLDER_ID?page_size=100" -H "X-API-Key: your apikey"

Search by name

curl "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/search?name=invoice" -H "X-API-Key: your apikey"

Search inside one folder

curl "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/search?name=invoice&parent_id=FOLDER_ID" -H "X-API-Key: your apikey"

Drive pagination and order

https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/children/FOLDER_ID?page_size=50&page_token=NEXT_PAGE_TOKEN&order_by=modifiedTime%20desc

Storage quota

curl "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/quota" -H "X-API-Key: your apikey"

GOOGLE DRIVE · POST

Create folders and upload files

Create a folder

curl -X POST "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"name":"Reports","mimeType":"application/vnd.google-apps.folder"}'

Create inside another folder

curl -X POST "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/FOLDER_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"name":"September","mimeType":"application/vnd.google-apps.folder"}'

Upload a file with Base64

curl -X POST "https://littleapi.online/api/v1/YOUR_DRIVE_API_ID/FOLDER_ID" \
  -H "X-API-Key: your apikey" \
  -H "Content-Type: application/json" \
  -d '{"name":"report.txt","mimeType":"text/plain","content_base64":"SGVsbG8gTGl0dGxlQVBJ"}'
API uploads use JSON + content_base64.

Multipart form-data is intentionally not accepted by this endpoint.

SECURITY

When do I need the API key?

✓ Public Sheets GET: no key when Public Read is enabled.
✓ Private Sheets GET: key required.
✓ POST, PATCH and DELETE: key required.
✓ Google Drive operations: key required.
Never publish a real API key in screenshots, public repositories or client-side source code that anyone can inspect.
