JSON

Large datasets remain one single array

LittleAPI does not split data into groups of 100. Firefox may display [0…99], [100…199] as a visual grouping in its viewer. JSON.parse(), Python, B4J and any client receive one single array.

Normal envelope

{
 "data":[{"id":"1","name":"Ana"}],
 "total":421,
 "limit":100,
 "offset":0,
 "returned":100,
 "has_more":true,
 "next_offset":100,
 "max_limit":1000,
 "meta":{"api_id":"YOUR_API_ID","name":"Customers","sheet":"Sheet1"}
}

Paginate until done

let offset = 0;
const rows = [];
while (true) {
  const page = await fetch(`${API}?limit=1000&offset=${offset}`).then(r => r.json());
  rows.push(...page.data);
  if (!page.has_more) break;
  offset = page.next_offset;
}

GOOGLE DRIVE

Files, folders, download and native export

Every Drive route requires X-API-Key. children/search accept page_size, page_token and order_by.

OWNER

Google OAuth and encrypted API-key recovery

These are dashboard routes: they require Authorization: Bearer USER_SESSION_JWT, not X-API-Key. Refresh tokens and recoverable API keys are encrypted server-side.

Never publish a real JWT, refresh token or API key.

B4J

Dim j As HttpJob
j.Initialize("", Me)
j.Download("https://littleapi.online/api/v1/YOUR_API_ID?limit=100")
Wait For (j) JobDone(j As HttpJob)
If j.Success Then
    Dim p As JSONParser
    p.Initialize(j.GetString)
    Dim result As Map = p.NextObject
    Dim rows As List = result.Get("data")
    Log(rows.Size)
End If
j.Release
Writes from client applications must protect the key.
