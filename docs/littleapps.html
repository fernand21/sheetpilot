LITTLEAPI · LITTLEAPPS

From API to app in five steps.

LittleApps turns an existing LittleAPI API into a responsive web application. There is no free-position canvas and no separate project to maintain: choose the data, the view, the fields and the visual style, then publish.

De API a aplicación en cinco pasos.

LittleApps convierte una API existente de LittleAPI en una aplicación web adaptable. No hay un lienzo de posiciones libres ni otro proyecto que mantener: elige los datos, la vista, los campos y el estilo visual, y publica.

START

Create or edit from the API card

Once an API exists, its dashboard card shows Create App. After saving a LittleApp, the same action changes to Edit App; published apps also show Open App.

Crea o edita desde la tarjeta de la API

Cuando existe una API, su tarjeta del panel muestra Crear app. Después de guardar una LittleApp, esa acción cambia a Editar app; las apps publicadas también muestran Abrir app.

RUNTIME

One runtime, many applications

LittleAPI does not generate a different HTML project for every user. The builder stores a compact configuration in Supabase and the shared LittleApps runtime interprets it. This keeps publishing fast and makes later edits immediate.

Un solo runtime, muchas aplicaciones

LittleAPI no genera un proyecto HTML diferente por usuario. El constructor guarda una configuración compacta en Supabase y el runtime compartido de LittleApps la interpreta. Esto hace la publicación rápida y permite que los cambios posteriores sean inmediatos.

PWA

Published apps expose a web app manifest. Supported browsers can offer installation without producing a separate APK.Las apps publicadas exponen un manifiesto web. Los navegadores compatibles pueden ofrecer instalación sin producir un APK separado.

CURRENT VERSION

What is available now

The first LittleApps version is intentionally simple: read data, search, paginate, show details, choose visible fields and publish a responsive app. Public Read must be enabled because no private end-user authentication layer is included yet.

Qué está disponible ahora

La primera versión de LittleApps es intencionalmente sencilla: leer datos, buscar, paginar, mostrar detalle, elegir campos visibles y publicar una app adaptable. Debe estar activada Lectura pública porque todavía no se incluye una capa de autenticación privada para usuarios finales.

Security:Seguridad: Do not publish an app from an API that exposes passwords, secrets or other private columns. Hide fields in the builder for presentation, but remember that Public Read still exposes the underlying endpoint.No publiques una app desde una API que exponga contraseñas, secretos u otras columnas privadas. Ocultar campos en el constructor sirve para la presentación, pero Lectura pública sigue exponiendo el endpoint subyacente.

LANGUAGES

English and Spanish are built in

The builder and the published runtime share the LittleAPI language preference. Users can switch language without recreating the app.

Inglés y español vienen integrados

El constructor y el runtime publicado comparten la preferencia de idioma de LittleAPI. Los usuarios pueden cambiar el idioma sin volver a crear la aplicación.
