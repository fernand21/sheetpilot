START

Create or edit from the API card

Once an API exists, its dashboard card shows Create App. After saving a LittleApp, the same action changes to Edit App; published apps also show Open App. From the builder you can save changes, publish again, or unpublish the app without deleting its configuration.

Crea o edita desde la tarjeta de la API

Cuando existe una API, su tarjeta del panel muestra Crear app. Después de guardar una LittleApp, esa acción cambia a Editar app; las apps publicadas también muestran Abrir app. Desde el constructor puedes guardar cambios, volver a publicar o despublicar la app sin borrar su configuración.

RUNTIME

One runtime, many applications

LittleAPI does not generate a different HTML project for every user. The builder stores a compact configuration in Supabase and the shared LittleApps runtime interprets it. This keeps publishing fast and makes later edits immediate.

Un solo runtime, muchas aplicaciones

LittleAPI no genera un proyecto HTML diferente por usuario. El constructor guarda una configuración compacta en Supabase y el runtime compartido de LittleApps la interpreta. Esto hace la publicación rápida y permite que los cambios posteriores sean inmediatos.

PWA

Published apps expose a web app manifest. Supported browsers can offer installation without producing a separate APK.Las apps publicadas exponen un manifiesto web. Los navegadores compatibles pueden ofrecer instalación sin producir un APK separado.

CURRENT VERSION

What is available now

LittleApps V3 separates every template screen into its own tab. Dashboard blocks can be reordered by drag and drop and configured as metrics or Bar, Line, Area, Pie or Doughnut charts. Each block chooses its category, value field, aggregation and item limit. Date fields are normalized for HTML date controls so existing Google Sheets dates remain visible when editing.

Qué está disponible ahora

LittleApps V3 separa cada pantalla de la plantilla en su propia pestaña. Los bloques del Panel pueden reordenarse arrastrando y soltando y configurarse como métricas o gráficos de Barras, Líneas, Área, Circular o Dona. Cada bloque elige categoría, campo de valor, agregación y límite. Los campos de fecha se normalizan para los controles HTML de fecha, por lo que las fechas existentes de Google Sheets permanecen visibles al editar.

Security:Seguridad: Published apps read through the LittleAPI backend, so the API key is never embedded in the HTML or PWA. Only fields marked visible are returned to the public runtime. Public CRUD actions are optional and should only be enabled when anyone with the app link is allowed to perform them.Las apps publicadas leen mediante el backend de LittleAPI, por lo que la API key nunca queda incrustada en el HTML o la PWA. Solo los campos marcados como visibles se devuelven al runtime público. Las acciones CRUD públicas son opcionales y solo deben activarse cuando cualquier persona con el enlace tenga permitido realizarlas.

LANGUAGES

English and Spanish are built in

The app can be configured as English-only, Spanish-only or bilingual. The language selector is hidden for single-language apps and only appears when both languages are enabled. Page names and common control texts can be edited from the builder.

Inglés y español vienen integrados

La app puede configurarse solo en inglés, solo en español o bilingüe. El selector de idioma se oculta en las apps de un solo idioma y únicamente aparece cuando ambos están habilitados. Los nombres de las páginas y los textos comunes de los controles pueden editarse desde el constructor.
