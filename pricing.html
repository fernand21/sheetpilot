Frequently asked questions

Are the widget features paid-only?

No. The embeddable widget, sheet/column selection, pagination and whole-sheet search are part of the LittleAPI workflow. Paid tiers primarily increase capacity and unlock advanced write/Drive features as shown above.

Does the iframe expose my API key?

No. Public widgets never include X-API-Key. Use them only for data you intentionally expose through Public read.

What counts as a request?

Each request to a published API counts once. CORS preflight requests do not consume quota. Counters reset at the start of each UTC month.

Are payments automatic?

No. Paid plans renew manually each month, so there are no automatic renewal charges.

Can I change plans without changing my API URL?

Yes. Plan changes affect configured capacity, not your API ID or endpoint URL.
