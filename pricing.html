Preguntas frecuentes

¿Qué cuenta como una consulta?

Cada request a una API publicada cuenta una vez. Las opciones CORS no consumen cuota. El contador se reinicia al comenzar cada mes UTC.

¿Qué ocurre al alcanzar el límite?

La API responde HTTP 429 con used, limit, remaining y reset_at. Así nunca hay cobros inesperados.

¿Puedo cambiar de plan?

Sí. La migración sólo aumenta o reduce el límite configurado; no cambia la URL de tu API.

¿Necesito iniciar sesión para consumir una API?

No. Las lecturas públicas funcionan sin cuenta. Sólo el propietario entra a LittleAPI para administrar la API y consultar su consumo.
